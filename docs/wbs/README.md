이름·담당자·시작/종료일·숫자 진행률은 원본과 동일함을 프로그램으로 검증했다. 기존 완료 1개도 원본 상태로 유지했으며 새 항목을 완료 처리하지 않았다. 대기와 80~90%가 함께 있던 행 등은 실제 구현/시험 근거를 따라 상태·비고를 정리했다. AWS 검증·1초 전체 복구 목표는 미검증으로 표시했다.

Argo/CI/보안 검사와 SBOM schema의 일부 작업 배정은 역할표의 업무 범위와 차이가 있어 V열에 팀 협의 필요로 표시했다. 재배정하지 않았다. 경과 일정과 변경 범위를 변경이력에 남기되 날짜를 자동 연장하지 않았다.

원본 도형·이미지·차트는 패키지 바이트 그대로 보존한다. Excel 수식 재계산을 켰고 집계 cache도 갱신했다. ZIP/XML와 수식·원본 보존 검증을 수행했으며 실제 Excel 화면의 시각 검토는 NOT_TESTED다. 수정본을 열어 긴 Q:W 열의 줄바꿈과 인쇄 범위는 발표 용도에 맞춰 조정할 수 있다.
