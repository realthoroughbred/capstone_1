# 통합 이전 원본 이력

이 폴더는 과거 실습 당시 작성된 파일의 보관본이다. 현재 통합본의 검사 결과로 사용하지 않는다.
원문에 있는 성공 표현·수치·명령은 그 시점의 기록이며, 현재 실행을 권하는 안내가 아니다.

| 보관 폴더 | 원본 브랜치 / 커밋 | 날짜 의미 | 원문에 기록된 환경 |
|---|---|---|---|
| [기준 브랜치](20261030-base-4c65215/) | `codex/devsecops-self-healing` / `4c6521503e1057d6289e7d71d45dae2511498e00` | 소스 커밋 2026-10-30; 주요 실습 보고서 작성 기준일 2026-10-23 | Windows/WSL Ubuntu, Docker Desktop, kind; 별도 과거 AWS 실습 기록 포함 |
| [팀원 브랜치](20261101-son-edb7f4a/) | `feature/son-eks-security-automation` / `edb7f4a11b70812e65a2fb7a41e9914905c197fa` | 소스 커밋 2026-11-01; 위험도 보고서 자체 표기 2026-11-01 00:15:26 KST. 날짜 미기재 문서는 원문 그대로 보관 | WSL Ubuntu, Docker Desktop, kind `team4`; EKS 미검증 |

두 폴더의 `manifest.json`은 원래 경로, 브랜치, 전체 커밋, 커밋 시각과 파일별 SHA256을 기록한다.
기준 브랜치의 문서 7개와 팀원 브랜치의 문서·원본 생성기·원본 정책 9개를 `git show COMMIT:PATH`의 바이트 그대로 복사했다.
원본 내부의 상대 링크가 가리키는 모든 소스까지 복제한 것은 아니다. 필요한 소스는 manifest에 적힌 커밋에서 확인한다.

과거 `evidence/`를 이 이력과 함께 배포하지 않으며, 원본 증거가 없는 보고서를 재생성하지 않는다.
루트의 기존 보고서도 덮어쓰지 않았다. [기존 생성기](../../scripts/generate-project-reports.py)는 이번 통합 작업에서 실행하지 않았다.
현재 검증과 실행 방법은 [통합 시연 안내](../INTEGRATION_DEMO.md)를 사용한다.
